## 1. 큰 구조

- **고객(Customer)** = 회원·비회원 공통. 회원은 1명당 1행, 비회원은 주문 1건당 1행입니다.
  - **회원(Member)**: 고객과 1:1입니다. memberId 값 = customerId 값입니다.
  - **비회원(Guest)**: 고객과 1:1입니다. guestId 값 = customerId 값입니다.
- **사업자(Business)**는 회원과 분리합니다. 회사 1개 = 1행이고, 직원 여러 명이 **사업자 소속 회원**으로 연결됩니다.
- 주소는 둘로 나눕니다.
  - 회원 배송지 주소: 사람마다 집·학교·회사 등
  - 사업장 주소: 회사의 본점·지점·공용 배송지
- 등급은 홀드를 풀고 **확정**했습니다. 구성은 다음과 같습니다.
  - 등급 정책 = 등급 템플릿(버전)
  - 등급 기준
  - 등급 혜택
  - 관리자 지정 등급
  - 등급 산정 기록(계산 근거)
  - 회원 등급 변경 이력(실제 변화)
- 다른 도메인 자리(예정): 주문(Order), 쿠폰 템플릿(CouponTemplate)

## 2. 주요 흐름

### 비회원 주문 조회 잠금
- 5번 틀리면 잠기고, 30분 뒤 자동으로 풀립니다.
- 바로 풀거나 비밀번호를 잊었으면, 주문 때 적은 휴대전화로 인증번호를 보냅니다. 맞게 입력하면 잠금이 풀리고 새 비밀번호를 정합니다. 이것은 본인인증이 아니라 그 번호를 지금 들고 있다는 확인입니다.

### 회원 로그인 잠금
- 아이디는 맞고 비밀번호가 틀리면, 그 로그인 수단에서 5번 실패 시 잠급니다.
  - 해제는 본인인증으로 합니다. CI가 회원 CI와 같아야 합니다. 미인증 회원은 이메일 인증번호로 풉니다.
  - 해제 후에는 비밀번호를 반드시 바꿔야 합니다.
- 없는 아이디는 계정 대신 IP 기준으로 막습니다(예: 1시간 20회 실패 → 1시간 차단).
- 소셜 로그인은 잠금 대상이 아닙니다.

### 사업자 소속 승인
- 회사를 처음 등록한 직원은 승인 없이 소속되고 **"회사 관리 담당"** 권한을 받습니다. 소속 승인 일시는 등록 시각으로 채웁니다.
- 이후 가입한 직원이 소속을 신청하면, 같은 회사의 회사 관리 담당이 승인하거나 거절합니다.
- 여기서 "회사 관리 담당"은 쇼핑몰 관리자와 다릅니다.

### 회원 탈퇴 (주문이 남아 있을 수 있음)

| 단계 | 상황 | 처리 |
|---|---|---|
| ① 요청 | 회원이 신청 | 새 주문은 막고, 로그인은 허용합니다(남은 주문 확인). |
| ② 보류 | 배송 중, 반품·교환 중, 환불 대기 | 거래가 끝날 때까지 기다립니다. 매일 도는 작업이 다시 확인합니다. |
| ③ 유예 | 진행 중인 거래가 없음 | 예: 7일 동안 철회할 수 있습니다. |
| ④ 완료 | 유예 기간이 끝남 | 바로 지울 것은 지우고, 보관할 것은 파기 예정 일시를 정합니다. |
| ⑤ 보관 정보 파기 | 보관 기간이 끝남 | 남은 기록을 지웁니다. |

탈퇴 완료 때 테이블별 처리입니다. 보관 기간은 모두 법 확인이 필요합니다.

| 테이블 | 처리 |
|---|---|
| 고객 | 행은 남깁니다(주문이 가리킴). 개인정보는 비우고 상태를 "개인정보 파기"로 바꿉니다. |
| 회원 | 행은 남기고 상태를 "탈퇴"로 바꿉니다. CI·생년월일 등 개인정보는 비웁니다. |
| 로그인 수단, 배송지 주소, 환불계좌 | 바로 삭제합니다. |
| 아이디 이력 | "탈퇴" 행을 추가합니다. 그 아이디는 6개월 동안 재사용할 수 없습니다. |
| 사업자 소속 회원 | 소속을 해제합니다(사유: 탈퇴). 회사의 마지막 직원일 때의 처리는 미결정입니다. |
| 법정대리인 가입 동의 | 종료합니다(사유: 탈퇴). 보호자 정보는 보관 후 삭제합니다. |
| 약관 동의 이력, 정보 변경 이력, 로그인 시도 기록, 고객 인증 기록, 등급 기록 | 보관 기간이 지나면 삭제합니다. |
| 쿠폰, 포인트 | 소멸합니다(각 도메인). |
| 주문, 결제 | 주문 도메인에서 법정 기간 보관 후 파기합니다. |

## 4. 오늘(2026-11-23) 사용자 결정 요약

**회원 유형·인증**
- 회원 유형은 개인 / 사업자(개인사업자·법인·기관·단체)이고, 외국인은 개인 안에서 구분합니다(룩플 벤치마킹).
- 중복 가입은 휴대폰 번호가 아니라 본인인증 CI로 막습니다.
- 한국 통신사를 쓰지 않는 외국인은 이메일 인증을 하고 미인증 회원이 됩니다(혜택·등급 없음).

**로그인**
- 로그인 수단은 자체 아이디 + 네이버·카카오·구글이며, 한 계정으로 합칩니다.
- 중복이면 "이미 ○○로 가입된 회원입니다. 이 계정에 ~를 추가할까요?"라고 안내하고, 거절하면 새 계정을 만들지 않습니다(고객센터 안내).
- 아이디 변경은 30일에 1번, 1년에 4번까지입니다. 바꾼 아이디는 6개월 동안 재사용할 수 없고, 금지어는 영구 금지입니다.
- 비밀번호는 6개월마다 변경을 안내하고, "다음에 변경하기"를 둡니다.
- 로그인 실패 잠금은 본인인증으로 풉니다.

**14세 미만·미성년자**
- 14세 미만은 보호자 본인인증과 동의를 받아 가입합니다. 만 14세가 되면 보호자 동의를 종료하고 본인 동의를 다시 받습니다.
- 만 19세 미만 회원이 구매하면 주문마다 보호자 동의를 받습니다.

**비회원**
- 비회원은 주문 1건마다 고객 1행입니다.
- 주문 비밀번호는 8~16자, 영문과 숫자를 섞습니다.
- 5번 틀리면 30분 잠금이고, 휴대전화 인증번호로 바로 풀 수 있습니다.

**사업자**
- 사업자는 회사 단위로 분리하고 직원 여러 명을 둡니다.
- 공동대표는 대표자 테이블에 담습니다.
- 사업장 주소는 여러 개를 저장할 수 있습니다.

**탈퇴**
- 주문이 남아 있어도 탈퇴를 요청할 수 있습니다. 거래가 끝날 때까지 보류 → 유예 → 완료 순으로 진행하고, 보관 기간이 지나면 파기합니다.

**등급 (확정)**
- 6단계(브론즈·실버·골드·플래티넘·VIP·VVIP)입니다.
- 최근 6개월 실결제 금액과 구매 확정 횟수로 정합니다.
- 구매 확정 때 바로 승급하고, 매월 1일에 한 단계씩 강등합니다.
- 혜택은 쿠폰과 무료배송입니다.
- 관리자 지정 등급은 최소 보장 방식입니다.
