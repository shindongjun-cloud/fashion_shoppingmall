# 재설계 2/5 상품 도메인 초안 v2: 40개 테이블 (2026-11-24)

26개 초안(`02-product-draft-2026-11-24.md`)에 2026-11-24 사용자 피드백 2차를 반영한 판입니다. 반영 내용은 소재를 섬유·원단으로 나누기, 사이즈 국가별 표기·측정 분류, 상품 유형 기준 테이블, 거래처 주소·담당자, 과세 구분 확장, 상품정보제공고시 품목·항목·내용, 품질보증 정책, 상품 칸 보강, SKU 바코드입니다. 할인 관련 항목은 할인 도메인에서 다룹니다. 판매량·반품률은 계산 값이라 저장하지 않습니다(리포트 집계).
