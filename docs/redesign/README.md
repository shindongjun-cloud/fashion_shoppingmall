## 고객 26개 = 결정 11개

| # | 결정 지점 | 고른 방법 | 다른 방법 (안 고른 것) | 생긴 테이블 |
|---|---|---|---|---|
| 1 | 고객 정체 구조 | 슈퍼+서브 (고객 → 회원 / 비회원) | 단일 테이블, 계정·고객 분리, 파티 모델 | 고객, 회원, 비회원 (3) |
| 2 | 로그인 수단 | 1:N 테이블 | 회원에 칸, 소셜별 칸, 외부 인증 위임 | 회원 로그인 수단, 아이디 이력 (2) |
| 3 | 잠금·보안 판단 | 시도·인증 기록 쌓기 | 실패 횟수 칸만 두기 | 비회원 조회 시도, 회원 로그인 시도, 고객 인증 기록 (3) |
| 4 | 주소 | 주소록 1:N | 칸 1개, 주소1·주소2 칸 | 회원 배송지 주소 (1) |
| 5 | 사업자 | 사업자 + 구성원 | 회원에 사업자 칸, 파티 모델 | 사업자, 사업장 주소, 소속 회원, 대표자 (4) |
| 6 | 미성년자 | 보호자 동의 기록 | 미성년자 가입 금지 | 법정대리인 가입 동의, 미성년자 구매 동의 (2) |
| 7 | 약관 동의 | 약관 버전 + 동의 이력 | 여부 칸, 여부+일시 칸 | 약관, 약관 동의 이력 (2) |
| 8 | 환불계좌 | 고객에 저장(암호화) | 환불할 때마다 입력 | 고객 환불계좌 (1) |
| 9 | 정보 변경 기록 | 범용 변경 이력 | 주제별 이력, 스냅샷 | 고객 정보 변경 이력 (1) |
| 10 | 등급 | 정책 버전 + 산정 + 이력 | 등급 칸, 등급 마스터만 | 등급 정책, 등급 기준, 등급 혜택, 관리자 지정 등급, 등급 산정 기록, 등급 변경 이력 (6) |
| 11 | 탈퇴 | 단계 관리 + 익명화 | 행 삭제, 소프트 삭제 | 회원 탈퇴 관리 (1) |

상품 결정 지점(8개)은 `02-product-draft-2026-11-24.md`의 1절에 있습니다.
