# 결제 3~5단계: 테이블 정의 (2026-11-26)

결제 16개와 공통 1개(금융기관)를 정의합니다. 결정과 이유는 `01-design-methods.md`, 검증 조건은 `03-integrity.md`에 있습니다. 모든 테이블 끝에 시스템 칸 4개(생성일시, 생성자, 수정일시, 수정자)가 있습니다. 표기는 2026-11-27에 정했습니다: DB·SQL은 스네이크(`created_at`), 코드는 카멜 + Prisma `@map`. 이 문서의 물리명(카멜)은 7단계 SQL을 만들 때 한꺼번에 바꿉니다. 2026-11-27 배송 설계 때 결제 칸 4개와 에스크로 칸 1개를 더했습니다(맨 아래 "배송 설계 때 고친 것"). 아래 전체 목록의 칸 수는 2026-11-26 기준입니다(결제 40 → 44, 에스크로 15 → 16).

## 전체 관계

```
결제사 가맹점 ─1:N─ 결제사 가맹점 수수료
      │
      1:N
      ▼
주문 ─1:N─ 결제 ─1:1─ 카드 / 간편결제 / 계좌이체 / 가상계좌 상세 ── 금융기관
            │    └1:1─ 에스크로
            ├─1:N─ 상태 이력
            ├─1:N─ 결제 취소 ─┬─ 현금영수증 (취소분)
            │                └─ 세금계산서 (수정분)
            ├─1:N─ 현금영수증 / 세금계산서
            ├─1:N─ 통신 기록 / 웹훅 수신
            └───── 대사 차이 ─N:1─ 대사 실행
```

## 2. 결제 카드 상세 (PaymentCard): ③ 1:1 상세
