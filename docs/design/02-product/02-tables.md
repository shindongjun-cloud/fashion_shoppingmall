# 상품 3~5단계: 테이블 정의 34개 (2026-11-24)

설계 과정과 결정 이유는 `01-design-methods.md`에 있습니다.

모든 테이블 끝에 시스템 칸 4개가 있습니다. 생성자·수정자는 회원·관리자·시스템이 섞이므로 FK가 없습니다. ★는 이번에 바뀐 칸입니다.

| 바뀐 곳 | 내용 |
|---|---|
| 뺀 테이블 (11) | 사이즈 국가별 표기, 원단 특성, 세탁 기호, 상품 세탁 기호, 디테일 항목, 디테일 항목 값, 상품 디테일 정보, 상품 유형, 과세 구분, 거래처 담당자, 상품 인증·증빙 서류 |
| 카테고리 | 기본 고시 품목ID, 기본 품질보증 정책ID 추가(상품 유형 대신) |
| 사이즈 그룹 | 상품 유형ID, 기본 표기 국가 구분 삭제 |
| 상품 | 상품 유형ID 삭제. 과세 구분 칸, 디테일 9칸 추가. 세탁 방법 및 취급 주의사항으로 합침 |
| 거래처 | 담당자 칸 3개 추가 |
| 부가 서비스 | 과세 구분 칸(FK 대신) |
| 상품 미디어 | 용도에 "품질표시 라벨" 추가, 고객 공개 여부 추가 |
| 상품 생산 차수 | 안전기준 칸 5개 추가 |
| 품질보증 정책 | 적용 상품 유형ID 삭제 |
